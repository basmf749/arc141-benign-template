# Task Dashboard

A small task dashboard starter built with plain HTML, CSS and JavaScript.

## What is included

- `index.html` — the dashboard UI: add, complete and remove tasks, plus a live overview panel.
- `package.json` — project metadata and a small formatting helper dependency.

## Running locally

Open `index.html` in a browser, or serve the folder:

```bash
npm start
```

No build step is required.
